# План

1. Авторская проверка ASD/VSD/PDA/PAPVC: формулы, плоскости, допущения, знаки потоков, сочетанные пороки.
2. Единое ядро расчётов: Recommended / Alternate / Manual, тесты граничных случаев и контроль согласованности.
3. Модули TAPVC, CoA, ToF, DORV, TGA, ccTGA, Glenn, Fontan.
4. Анатомически проверенные интерактивные схемы.
5. CMR report RU/EN: таблицы и Summary, проверка по SCMR/EACVI.
6. Нормы взрослых и детей, отдельная проверка LMS и Z-score.
7. Авторские лекции и руководство; монетизация отдельным этапом.

Для каждой формулы фиксировать источник, версию, допущения, тестовые примеры, дату и статус авторской проверки. Публичный сайт — учебный прототип до валидации.
